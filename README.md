## Описание проекта

Учебная практика посвящена автоматизации производственных процессов при выпуске медицинских изделий одноразового применения. В качестве конкретного изделия рассматриваются одноразовые шприцы. Основным автоматизируемым бизнес-процессом является Оформление и запуск производственной практики. Целью работы является разработка программного обеспечения для автоматизации основного бизнес-процесса.
