## Описание проекта

Учебная практика посвящена автоматизации производственных процессов при выпуске медицинских изделий одноразового применения. В качестве конкретного изделия рассматриваются одноразовые шприцы. Основным автоматизируемым бизнес-процессом является Оформление и запуск производственной практики. Целью работы является разработка программного обеспечения для автоматизации основного бизнес-процесса. 

## Архитектура решения

Проект реализуется как **Telegram-бот на Java** с **микросервисом на Python**:

- **Telegram-бот (Java, Spring Boot)** — интерфейс для оператора участка: получение задания, регистрация партии, уведомления. Бот взаимодействует с Telegram Bot API и отправляет запросы к микросервису по HTTP.
- **Микросервис (Python, FastAPI)** — бизнес-логика: валидация данных, генерация номеров партий, работа с БД. Предоставляет REST API для бота.

Взаимодействие между компонентами — через REST API (JSON).
