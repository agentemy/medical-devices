## Описание проекта

Учебная практика посвящена автоматизации производственных процессов при выпуске медицинских изделий одноразового применения. В качестве конкретного изделия рассматриваются одноразовые шприцы. Основным автоматизируемым бизнес-процессом является "Подготовка и запуск производственной партии одноразовых медицинских шприцев". Целью работы является разработка программного обеспечения для автоматизации основного бизнес-процесса. 

## Архитектура решения

Проект реализуется как **Telegram-бот на Java** с **микросервисом на Python**:

- **Telegram-бот (Java, Spring Boot)** — интерфейс для оператора участка: получение задания, регистрация партии, уведомления. Бот взаимодействует с Telegram Bot API и отправляет запросы к микросервису по HTTP.
- **Микросервис (Python, FastAPI)** — бизнес-логика: валидация данных, генерация номеров партий, работа с БД. Предоставляет REST API для бота.

Взаимодействие между компонентами — через REST API (JSON).

## КТ2 — Аналитический этап

Разработана BPMN-модель процесса подготовки и запуска производственной партии одноразовых медицинских шприцев.

На диаграмме представлены участники процесса, последовательность действий, проверки наличия материалов, корректности документации, доступности оборудования и готовности к запуску. Показаны используемые данные и варианты завершения процесса: запуск партии или перенос с фиксацией причины.

Исходник модели: `models/bpmn.bpmn`


## Запуск программы

На этапе КТ2 реализована консольная программа на Python. Она рассчитывает потребность в материалах, проверяет остатки, подбирает оборудование и фиксирует запуск или перенос партии. Демонстрационные данные хранятся в `src/demo_data.json`. Для запуска достаточно Python 3, дополнительные пакеты устанавливать не нужно.

Из корня репозитория `medical-devices` выполните:

python src/main.py

По умолчанию запускается сценарий `ready`, в котором партия успешно запускается. Чтобы проверить перенос запуска, передайте один из сценариев:

| Сценарий | Причина переноса |
| `shortage` | Недостаточно материалов |
| `busy` | Требуемое оборудование недоступно |
| `quality_rejected` | Проверка готовности перед запуском выявила несоответствие |
